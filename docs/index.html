PocketStudio 是一款原生 macOS 应用，通过 Wi-Fi 在 Mac 上实时取景、拍摄、控制云台，并直接在电脑上录制预览画面。

为 Mac 原生打造：AppKit、Swift 6、macOS 26 Liquid Glass 设计语言。

沉浸式全窗口实时取景

类似 Netflix 的观看体验：鼠标静止时控件自动隐藏；画面自动适配真实视频比例，竖拍画面同样完美呈现。

右侧竖向拍摄栏

拍照 / 录像 / 慢动作 / 延时一键切换，统一的快门按钮。

云台控制

鼠标拖动即可转动云台，支持一键回中与云台模式切换。

Mac 端直录

直接在 Mac 上录制实时预览流，无需重新编码。

状态一目了然

状态栏实时显示电量、存储空间与姿态信息。

自动重连 + 视频看门狗

连接断开自动恢复，视频流卡住时自动拉起。

新手友好引导

一步步带你完成 macOS 本地网络与蓝牙权限设置。

调试面板

内置调试面板，便于排查连接与视频流问题。

实验中

Pocket 4 / 4P 支持

即将到来：支持 Osmo Pocket 4 / 4P 及 HEVC 实时取景。

三步，开拍。

蓝牙负责唤醒与配对，Wi-Fi 负责高速画面传输。

1

BLE 唤醒

通过蓝牙唤醒 Osmo Pocket 3 并完成配对。

2

Wi-Fi 连接

建立与相机的 Wi-Fi 链路，实时画面直达 Mac。

3

开始拍摄

切换模式、按下快门、拖动云台，或直接在 Mac 上录制。

系统要求

原生、轻量，专为最新 macOS 打造。

操作系统macOS 26+
相机DJI Osmo Pocket 3
连接蓝牙 + Wi-Fi
